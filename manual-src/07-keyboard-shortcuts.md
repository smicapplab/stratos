# 7. Keyboard Shortcuts

Stratos is designed for power users. You can navigate the entire interface, create tasks, and assign work without ever taking your hands off the keyboard.

## Global Shortcuts

These shortcuts work from anywhere in the application.

| Shortcut | Action |
|----------|--------|
| `Cmd + K` (Mac) or `Ctrl + K` (Win) | Open the Global Command Palette / Search |
| `Esc` | Close any open modal, drawer, or dropdown |

## Board Navigation

When viewing a Kanban board, the following shortcuts allow you to traverse and manipulate tasks:

| Shortcut | Action |
|----------|--------|
| `Arrow Keys` | Move focus between columns (Left/Right) and tasks (Up/Down) |
| `Enter` | Open the focused task in the Task Drawer |
| `C` | Create a new task in the currently focused column |
| `Space` | Open the assignee dropdown for the focused task |

## Task Editor

When typing in a task description or comment, you can use Markdown-style shortcuts:

| Shortcut | Action |
|----------|--------|
| `# ` (followed by space) | Create an H1 heading |
| `## ` (followed by space) | Create an H2 heading |
| `* ` (followed by space) | Start a bulleted list |
| `1. ` (followed by space) | Start a numbered list |
| `` ` `` (backticks) | Format text as inline code |
| `@` | Trigger user mentions |
